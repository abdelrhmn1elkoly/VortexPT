1. Introduction & Core Architecture

Vortex PT is a specialized desktop engineering suite designed to bridge the workflow gap between finite-element post-tensioned design software (Bentley RAM Concept and ADAPT-Builder) and construction-ready shop drawings in AutoCAD (.dwg / .dxf).

Traditional shop drawing workflows require draftsmen to manually trace tendon spans, hand-calculate chair support heights, transcribe profile points, and manually draw anchor setbacks. Vortex PT eliminates these manual steps, reducing a multi-day drafting task to under 30 seconds while guaranteeing zero transcription errors.

Target Users
Structural Engineers, PT Contractors, CAD Detailers
Execution Environment
100% Offline Desktop, Windows 10 / 11 64-bit

Bentley RAM Concept (*.cpt, *.cpt8) & ADAPT-Builder (*.adm with .inb/.inp)

02 Opening & Importing Models

2.1 Supported File Types

Vortex PT natively imports structural data directly from the industry's two dominant post-tensioned design platforms:

  • Bentley RAM Concept Files (*.cpt, *.cpt8): Direct parsing of proprietary binary archives including slabs, drop panels, openings, columns, shear walls, beams, latitude tendons, longitude tendons, and control points.
  • ADAPT-Builder Project Models (*.adm with companion *.inb / *.inp): Direct loading of ADAPT Floor Pro, MAT, and Edge models. You select the native .adm file directly in Vortex PT, which automatically reads the companion .inb / .inp file of the same name.

2.2 ADAPT-Builder Import Architecture (.adm + .inb)

In ADAPT-Builder, models are saved with the default extension .adm. To import an ADAPT model into Vortex PT:

  • Vortex PT directly opens the .adm file from the file open dialog.
  • Mandatory Pairing Rule: Beside your .adm file in the same folder, there must exist a companion Generic Model file (.inb or .inp) bearing the exact same base name (e.g. Building_Level2.adm paired with Building_Level2.inb or Building_Level2.inp).
  • Vortex PT also automatically checks companion project subfolders (<model_folder>/<model_name>/) and ADAPT automatic backup directories (backup/).
💡
How to Export from ADAPT-Builder
  1. Open your project in ADAPT-Builder (Floor Pro, MAT, or Edge).
  2. Go to menu: File → Export → Generic Model (*.inp / *.inb).
  3. Save the exported file in the same directory as your .adm file with the matching name.
  4. In Vortex PT, click Open Model and select the .adm file. Vortex PT reads the paired data and instantly renders the entire floor plate with 100% geometric fidelity!

2.3 Step-by-Step Model Loading Workflow

  1. Click the vibrant electric cyan "+ Open Model" button located at the top left of the workspace toolbar, or press the universal shortcut Ctrl + O.
  2. In the Windows File Dialog, browse to your model directory and select your Bentley RAM Concept (.cpt / .cpt8) or ADAPT-Builder (.adm) file.
  3. Vortex PT initiates its multi-stage extraction pipeline:
    • Reads concrete geometry: slab perimeters, thickness zones, drop caps, and core openings.
    • Extracts structural supports: columns, shear walls, and perimeter foundation lines.
    • Assembles continuous tendon strings from segmental FEA elements, calculating curvature, inflection transitions, and anchorage conditions.
  4. Upon completion, the main CAD viewport renders the complete slab floor plate, and the Project Metrics Card populates immediately.
Figure 2.1: Live 2D CAD Workspace after opening B01-PART 2.cpt. Displays 70 continuous tendons, slab boundaries, drop panels, columns, the floating Project Metrics HUD, and Tendon Y-3 longitudinal profile.

2.4 ADAPT-Builder Exact Elongation & Area Extraction

When importing ADAPT-Builder models (.inp / .inb), Vortex PT guarantees 100% computational fidelity:

  • Exact Cross-Sectional Area (Aps): Preserves the exact total strand area (e.g. 197.4 mm² for 2 strands) as modeled in ADAPT, eliminating rounding discrepancies in force and stress calculations.
  • End Elongations (End 1 & End 2): Extracts theoretical jacking extensions for both stressing boundaries directly from ADAPT design output tables, matching fabrication tickets identically.

2.5 RAM Concept Transverse Beam & Flat Support Fidelity

Vortex PT incorporates intelligent geometry heuristics to handle complex post-tensioning conditions in Bentley RAM Concept (.cpt):

  • Transverse Beam Steps & Band Crossings: Tendons crossing transverse band beams maintain true physical trajectory. Slices crossing linear ramp steps evaluate without spurious sag artifacts.
  • Elimination of False Low Sags: Intermediate chairs between two high support zones strictly maintain high profile chair height (e.g. 155 mm) rather than dipping into artificial sags.
  • Slanted Edge Collinear Dims: Non-orthogonal slab perimeters generate aligned dimension strings running parallel to the exterior concrete edge, preserving architectural boundaries.

04 Parabolic Tendon Profiling & Chairs

4.1 The Longitudinal Profile Viewer

Selecting any tendon triggers the bottom Longitudinal Tendon Profile Dock. This viewer displays the continuous cross-sectional elevation of the tendon from its starting anchor to its ending anchor.

Figure 4.1: Continuous 11-Span Longitudinal Elevation Profile of Tendon X-16. Features high support points over columns, low mid-span sags with fabricated chair heights, pan box setback blocks, and span dimension strings.

4.2 Mathematical Profile Modeling & Inflection Points

Vortex PT calculates true multi-span second-degree and third-degree reverse parabolic curves across each support bay:

  • High Support Points (Hi): Peak elevations located over column centerlines or interior wall supports.
  • Low Sag Points (Li): Maximum sag elevations located at mid-spans to optimize balancing load.
  • Inflection Transition Points (Xinf): Mathematically computed points of zero curvature where the curve transitions smoothly between concave-up and concave-down parabolas.

4.3 Automatic Chair Support Calculations

Fabrication chairs are calculated at regular field intervals (default 1,000 mm) along the tendon:

📐
Chair Height Governing Formula
Fabricated Chair Height = Tendon Centerline Profile (CGS) − Deduction Constant
Calculated chair heights are automatically rounded to your specified fabrication increment (e.g. 5 mm steps).
⚠
Anchor Placement vs. Chairs
Anchorage points (Live Jacking Ends and Dead Cast-In Anchors) are physical fittings affixed to the slab formwork. Vortex PT excludes anchors from the chair table summary to prevent accidental chair over-ordering on site.

4.4 Wide Beam & Beam Exit Transition Chairs

Vortex PT 1.4 introduces intelligent multi-depth soffit referencing across beams and slabs:

  • Wide Beams (> 500 mm Width): When beams are wider than 500 mm, tendons running along or terminating within the beam sit directly on the wide beam soffit formwork. Chairs inside wide beams reference the beam soffit directly without deducting stem depths, matching real-world site carpentry.
  • Narrow Stem Beams (≤ 500 mm Width): Tendons crossing narrow stem beams maintain their reference to the main slab soffit formwork with proper stem deductions.
  • Beam Exit Transition Chairs: When a tendon exits a deep beam into an adjacent thinner slab, chairs immediately beyond the beam boundary strictly reference the slab soffit. The engine guarantees zero erroneous beam-depth inheritance outside the physical beam boundaries.

05 Engineering Compliance & QA Alerts

5.1 Automated Quality Assurance Engine

Every imported model undergoes continuous geometric and structural integrity diagnostics based on ACI 318-19 and the Post-Tensioning Institute (PTI) Manual. When an issue is detected, an amber "⚠ QA Warning" badge illuminates in the top command bar.

Figure 5.1: Engineering Compliance & QA Alerts diagnostic modal showing automated violation detection, severity ratings, and actionable structural recommendations.

5.2 Core Diagnostic Rules

A. Minimum Concrete Cover Verification

  • Top Cover Check: Verifies that Slab Depth − Profile Elevation ≥ Min Cover (default: 25 mm).
  • Bottom Cover Check: Verifies that Profile Elevation ≥ Min Cover (default: 25 mm).
  • Alert Condition: If strand trajectory violates cover rules at high or low points, Vortex PT flags the exact bay and span coordinate.

B. Double Live End Minimum Length Threshold

  • Rule Rationale: Short tendons configured with live stressing jacks at both ends lead to wedge seating loss issues and unnecessary labor costs.
  • Threshold Setting: In Settings, you configure the warning threshold (e.g. 35.0 m). Tendons with two live ends shorter than this threshold trigger an alert advising a single live end configuration.

C. Two Dead Ends Critical Validation

  • Fatal Check: Scans the model for any tendon terminated with dead-end (cast-in) anchors at both boundaries.
  • Severity: High / Critical. Tendons cannot be stressed if both ends are encapsulated in blind anchors.

6.3 Persistent User Templates & Roaming AppData Isolation

To ensure your drafting customizations are never lost when installing software updates, Vortex PT isolates active user templates from the application binary directory:

  • Active User Template Location: %APPDATA%\VortexPT\templates\blocks.dwg and blocks.dxf.
  • Zero-Overwrite Protection: Software updates install exclusively into C:\Program Files\Vortex PT. The installer never touches or overwrites your custom blocks or settings.json in AppData.
  • Dedicated Controls in Settings:
    • Edit in AutoCAD: Directly launches your live AppData template in AutoCAD.
    • Open Folder: Opens the AppData templates folder in Windows Explorer.
    • Reset Defaults: Safely restores factory template blocks while creating an automatic timestamped backup of your current blocks.

07 AutoCAD DWG/DXF Shop Drawing Export

7.1 Export Console Overview

Click the "Export" icon in the left navigation rail or press Ctrl + E to access the production drawing generator.

Figure 7.1: Production Drawing Export Console. Configure drawing types, layout styles, annotation layers, and direct AutoCAD DWG / DXF generation.

7.2 Production Drawing Configurations

A. CAD Drawing Type

  • Shop Drawing (Full Fabrication & Chairs): Complete fabrication-level drawing including chair support tags, remainder dimensions, tendon IDs, elongation markers, and anchor blocks.
  • Design Drawing (Profile Points Only): Streamlined consultant drawing with Kholy profile point blocks and high/low labels.

B. Sheet Layout Options

  • Side-by-Side Dual Plan [Recommended]: Automatically offsets and places the Latitude drawing and Longitude drawing side-by-side on a single DWG layout for streamlined contractor printing.
  • Combined Plan: Both Latitude and Longitude systems superimposed on a single floor plan.
  • 2 Separate Plans: Generates distinct independent files (e.g. Model_Lat.dwg and Model_Long.dwg).

7.3 Embedded Features

  • AutoCAD Layer Architecture: All geometries are partitioned into dedicated layers (PT-TENDON-LAT, PT-TENDON-LONG, PT-CHAIRS, PT-ANCHORS, PT-DIMS) matching standard drafting protocols.
  • Embedded Schedule Table: Optionally embeds the complete PT tendon schedule directly into model space.

7.4 Detailing Rules for Best Output in AutoCAD

  1. Recommended Sheet Layout: Always select Side-by-Side Dual Plan. This places the Latitude and Longitude drawings side-by-side with an automatic bounding offset, creating clean, professional drawings ready for plotting.
  2. Dimension Style Separation: Vortex PT generates separate dimension styles:
    • PT_LONGITUDINAL_DIMS: Tailored for tendon span lengths and remainder segments.
    • PT_SPACING_DIMS: Specially scaled for out-of-plan tendon spacing strings.
  3. Chair Deduction Tuning: Verify high-point deduction (default: 10 mm) and low-point deduction (default: 15 mm) match site chair sizes. The minimum physical chair height is clamped to 20 mm to prevent fabrication tickets for unbuildable chairs.
